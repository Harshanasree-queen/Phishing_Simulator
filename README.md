🎣 Phishing Attack Simulator Tool  

A **Flask-based phishing simulator** built for **cybersecurity awareness and training**.  
This tool demonstrates how phishing attacks can be simulated in a safe and controlled environment, allowing educators and security teams to raise awareness of phishing risks.  

---

## 🚀 Features  
- Flask-powered **web application**  
- Landing page that mimics a phishing attempt  
- Captures **user actions** and **timestamps**  
- Stores responses in memory for analysis  
- **Results dashboard** to review captured interactions  

---

⚙️ Requirements  
- Python 3.x  
- Flask  

Install dependencies:  
```bash
pip install flask

▶️ Usage

Clone the repository:

git clone https://github.com/yourusername/phishing-simulator.git
cd phishing-simulator


Run the Flask app:

python app.py


Open the application in your browser at:

http://127.0.0.1:5000/


Interact with the phishing page and view results at:

http://127.0.0.1:5000/results
